[Releases](https://github.com/XueRenYi0/zhima-qiji-updates/releases/latest)

## 应用内一键更新

0.2.4 起默认更新源已内置，打开应用点右上角「更新」即可。

更新源：

```text
https://github.com/XueRenYi0/zhima-qiji-updates/releases/latest/download/latest.json
```

也可以换成局域网共享或同步盘里的 `latest.json`。

## 数据说明

题库、进度、语音笔记只保存在本机，不会上传到这个仓库。

## 版本

- v0.3.14：批注改双层画布，写字不再闪烁/中断；笔形光标改 PNG；搜索结果批量笔记和同步笔记。
- v0.3.13：批注普通手写不再中途截断，单点保留圆点；搜索结果支持批量笔记，搜索练习可把当前笔记同步到全部结果。
- v0.3.12：题库页顶部新增醒目的关键词搜索框；搜索时直接显示全库结果，可逐题练习和写笔记。
- v0.3.11：批注改为笔形光标；题库支持关键词搜索、搜索结果逐题练习和题目笔记；忽略后各级题量同步减少；江苏教综目录细化到 77 个知识点。
- v0.3.10：大型教育综合题库按江苏教综目录重整为 13 章节 / 62 知识点，题目按题干归入细知识点；每天 1808 题 / 30 天约 61 题。
- v0.3.9：大型教育综合题库按江苏教综标准目录重整为 13 章节 / 62 知识点；每天按总题量平均分配约 60 题。
- v0.3.8：题库知识点分层与单独练习；学科/当天/知识点三级进度条同步更新，并修正百分比换算。
- v0.3.7：题库按章节/知识点分层，点知识点可单独练习；新增学科/当天/知识点三级同步进度条。
- v0.3.6：AI 评审团默认自动带 3 个同服务商模型；题库可彻底删除；忽略题目会真正从题库移除，题数同步减少。
- v0.3.5：API 设置改成服务商下拉；填一个 Key 自动检测模型；阿里云百炼同一个 Key 可用于文字、语音识别和抽查朗读。
- v0.3.4：批注自动带当前题目卡片、免截图；荧光笔/画笔停顿自动拉直或校正图形；新增自定义色盘；画笔字迹平滑优化。
- v0.3.3：Word 导入支持旧版 .doc，并按文件真实内容识别格式；文件不完整/加密/改后缀会给出明确提示。
- v0.3.2：没填 API Key 时拖入题库自动改用规则解析；兼容题干与选项同行的题库；拖错位置不会再打开文件。
- v0.3.1：更新检查/下载增加直连与镜像回退，连不上时可打开下载页；抽查点关闭后立即停止朗读和录音。
- v0.3.0：新增一键恢复 ZIP（恢复前自动备份当前数据，完成后自动重启）。
- v0.2.9：抽查 CosyVoice 自然语音 + 自动倾听/自动下一题；含录音/批注的完整备份 ZIP；答对音效恢复原提示音。
